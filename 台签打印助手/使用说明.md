# 台签打印助手

一个 Windows 小工具：把姓名以**最大字号铺满** **15×8cm** 台签，字多时**每段仍是一行、整行横向撑满**（不会拆成两行）；自带**横向/纵向两个字形拉伸滑块**，可以自己决定字拉宽拉窄、拉高拉扁到什么程度；A4 纸一次排 3 张，**贴边排版只需 4 刀**就能裁完，直接送打印机。

---

## 一、怎么用

1. 双击 `台签打印助手.exe`（独立运行，不用装任何东西）。
2. 在左侧「① 台签内容」里一行一个名字，例如：

   ```
   张三
   李四
   王五
   ```

3. 选字体 → 点「🖨 打印」→ 在打印对话框里确认纸张是 **A4、纵向**，然后打印。
4. 打印完照下面「四、裁剪」的 4 刀切完即可。

想先看看效果，点「导出 PDF」，或用右上角的预览区（预览就是最终打印效果，所见即所得）。

---

## 二、界面说明

### ① 台签内容
- **一行一个名字**（一行 = 一张台签），超出 3 个会自动分到下一页 A4。
- **字多也不会变小，也不会拆成两行**：程序把整行**横向撑满**台签宽度——
  字多就把字压窄一点，字少就拉宽一点，行高始终保持最大。8 个字是一行、
  12 个字还是一行。
- 想再挂职务/单位，用竖线分隔，**每段各占一行**：

  ```
  张三|销售总监
  慕容雪见·兰|编制质控单位|专家组长
  ```

  几段**一样高、各占一行**，每段各自撑满整宽，整张台签被均匀填满
  （见交付目录里的 `示例-排版对比.png` 左列）。

### ② 字体
- 下拉框列出**本机已安装的全部字体**，可以直接打字搜索（如输入「黑」筛出黑体）。
- 下面一排是常用中文字体快捷键，本机没装的会自动变灰。
- **加粗**：台签建议开，远看清楚。
- **黑底白字**：白纸黑字是常规做法；黑底白字适合彩色打印机/深色卡纸。
- **自动最大字号**：默认。程序会算出"刚好撑满"的字号，同时保证不出框。
- **指定字号**：想固定大小时用（单位 pt，1pt ≈ 0.353mm）。指定字号时不做任何缩放。
- **字多时**（三种填充方式）：

  | 选项 | 效果 | 什么时候用 |
  |---|---|---|
  | **拉伸铺满**（默认） | 每段一行，横向拉伸撑满整宽。字多字少都是**一行**，行高拉满 | 常规台签；名字较长；要和以前那套工具效果一致 |
  | **自动折行铺满** | 不改变字形比例，自动折成 2~4 行，取最大字号 | 名字特别长、又不想让字被压窄时 |
  | **单行等比** | 只按宽度等比适配，字最小、上下留白多 | 只要一个不变形的小签名式排版 |

- **行距 / 副标题字号**：只在「自动折行铺满」模式下生效，其它模式会自动置灰。
- **字形拉伸**（两个滑块：横向 ↔ / 纵向 ↕）：在「自动铺满」的结果上，再手动把字压一压或拉一拉。
  范围 **0.40× ~ 2.50×**，**1.00× = 不动**。往左拖变瘦、往右拖变胖；
  点滑块右边的数字按钮可一键回到 1.00×。三种填充方式下都有效。

  | 拖动方向 | 实际效果 |
  |---|---|
  | 横向 **> 1.00×** | 宽度本来已撑满，于是改为压低字号 → 字更**扁、更宽** |
  | 横向 **< 1.00×** | 宽度按比例收窄、两侧留白，高度不变 → 字更**瘦** |
  | 纵向 **> 1.00×** | 高度本来就顶满行槽，于是改为压小字号 → 字更**瘦、更高** |
  | 纵向 **< 1.00×** | 高度按比例压低、上下留白，宽度仍撑满 → 字更**扁** |
  | 两轴一起往大拖 | 两个方向互相抵消，外观几乎不变（本来已撑满） |
  | 两轴一起往小拖 | 整块字等比例缩小，四周留白 |

  不管怎么拖，程序都会把字号往下让，所以**永远不会溢出台签**。
  效果见交付目录里的 `示例-字形拉伸.png`（3×3 矩阵，一眼看出两个方向各自的影响）。

### ③ 台签尺寸与排版

| 参数 | 说明 |
|---|---|
| **排版方式** | **贴边紧凑**（默认）：台签从纸张左上角开始紧贴排列，右侧和下方留边角料，**只在这两个方向下刀**。 **整页居中**：整块版心在纸上居中，四周留白，需要沿每张台签的四条边分别裁。 |
| 台签宽 / 高 | 默认 **150 × 80 mm**。点「⇄ 互换」可切成竖版。 |
| 文字留白 | 文字与台签边缘的最小距离，默认 4mm。想让字更满就调到 2–3mm。 |
| 台签间距 | 仅「整页居中」模式有效。 |
| 纸张边距 | 仅「整页居中」模式有效。 |
| **切割标记** | **废料定位点**（默认，推荐）：只在**会被切掉的废料区**里印几根极短的灰线，每条刀口 2 个定位点。对齐下刀即可，**成品台签上一个标记都不留**。 **定位虚线**：沿下刀位置画贯通整页的浅灰虚线（已做遮蔽处理，线只留在废料那半边）。 **四角角标**：四角画向外的小 L 形（居中排版时用）。 **整圈边框**：沿台签边缘画一圈细线。 **不打印任何标记**：只有内容，自己用尺量。 |
| 纸张 | 默认 A4 纵向。改成别的规格后每页张数会自动重算。 |

排版参数下面有一行绿色提示，会直接告诉你**这一叠纸该怎么切、一共切几刀**，不用自己算。

### ④ 打印
- **打印机**：列出系统里的全部打印机，默认选中默认打印机。
- **整份份数**：整个文档打印几份。
- **每名字张数**：例如设成 2，张三就打印 2 张（一个人要两张台签时用）。
- **导出 PDF**：方便先存档/先看一眼，也可以拿到别处打印。

## 三、打印设置要点（重要）

打印对话框里请确认：

- 纸张：**A4**，方向：**纵向**
- **缩放 / Scale 设为 100% 或「实际大小」**，不要选"适应页面 / 缩小以适应"——否则尺寸会不准。
- 页边距设为「无 / 默认」即可，版面位置由本软件控制。

> 第一次使用建议先用普通纸试印一张，拿尺子量一下台签是否正好 150×80mm。如果偏小，多半是打印驱动的缩放没设成 100%。

## 四、裁剪（贴边紧凑模式，4 刀）

打印出来是这样一张 A4（`│` `─` 是印在**废料区**里的定位点，切完随废料一起丢掉）：

```
┌─────────────────┬───┬───────┐
│                 │   │       │
│      张三       │   │       │ 80mm
│                 │   │       │
├─────────────────┼───┼───────┤   ← 定位点：右侧两个短线跨在 80mm 处
│                 │   │       │ 80mm
│      李四       │   │       │
│                 │   │       │
├─────────────────┼───┼───────┤   ← 160mm
│                 │   │       │ 80mm
│     欧阳明月    │   │       │
│                 │   │       │
├─────────────────┼───┼───────┤   ← 240mm
│      废料       │   │       │ 57mm
└─────────────────┴───┴───────┘
       150mm         60mm
      ↑ 竖切 150mm：上、下两端各一个定位点，端头正好落在刀口上
```

**竖切线**（距左边 150mm）：纸的上、下两端在废料区各印一根横短线，
**线头正好对准 150mm**，两点连线就是刀口位置。

**横切线**（距上边 80 / 160 / 240mm）：右侧废料区各印两根**跨在刀口上**的短竖线，
把刀口对准两根线的中点下刀即可。

下刀顺序：

1. **第 1 刀（竖切）**：看上下两个定位点，在距纸左边 **150 mm** 处竖着切一刀，右侧 60mm 整条扔掉。
2. **第 2–4 刀（横切）**：从上边往下，在 **80 / 160 / 240 mm** 处各横切一刀。
   - 第 1 刀切出「张三」，第 2 刀切出「李四」，第 3 刀切出「欧阳明月」，
     同时把下方 57mm 的废料分出去。

**总共 4 刀**，得到 3 张 150×80mm 台签。所有定位点都在右侧/下方的废料里，
**成品台签上一个标记都不会有**。

> 实际操作时不必每次都从纸边量绝对位置——切完一刀后，把剩下的纸条以切口为基准**每次递进 80mm** 即可，更省事。

台签左上角的两条边是纸张本身的裁边，天然平整，不用切。

> 不喜欢任何标记？把「切割标记」设成「不打印任何标记」，自己用尺量；
> 想切回原来那种贯通虚线，选「定位虚线」即可。

## 五、常见问题

**Q：打印出来尺寸不对 / 大了一圈小了一圈？**
打印驱动的缩放不是 100%。在打印对话框的「首选项 / Preferences」里把缩放改成 100%。

**Q：最左侧台签的字靠边太近，或者边缘有一点点打不出来？**
打印机有 3–5mm 的不可打印边距。贴边模式下请把「文字留白」调到 **5–6mm**（默认为 4mm，一般激光打印机没问题）。

**Q：想要四周都留白、不用切那么齐？**
把「排版方式」改成「整页居中」即可，代价是要多切几刀。

**Q：成品台签边缘会不会留下打印的标记？**
不会。默认的「废料定位点」全部印在会被切掉的废料里。实测把渲染图按 4 刀裁开后，
逐像素扫描成品台签：3 张里有 2 张 **0 个杂点**，另外 1 张只有紧贴刀口处 0.085mm
（相当于 1 个像素）的痕迹，肉眼不可见。

**Q：虚线切完还剩一点在台签上？**
改用默认的「废料定位点」即可。若仍想用虚线，「定位虚线」模式已做遮蔽处理：
线只画在台签外侧的那一半，台签范围内不会残留。

**Q：字体列表里没有我想要的字体？**
列表读的是系统已安装字体。新装字体后重开一下软件。

**Q：名字很长，为什么没有像别家工具那样把台签铺满？**
从 v5 起默认用**拉伸铺满**：每段一行，整行横向拉伸到撑满宽度、行高拉满。
12 个字「中国国际航空股份有限公司」从旧版单行 11.8mm 提到 **26.6mm**。
如果显示成两行，说明「字多时」被切到了「自动折行铺满」，切回「拉伸铺满」即可。

**Q：名字特别长会不会出框？**
不会。横向缩放有上下限（压到 0.45 倍就不再压，改为缩字号），
并留 1.5% 安全余量；实测所有字数的溢出量都是 0，水平居中偏差 ≤ 0.12mm。

**Q：字被横向压窄了，看着有点挤？**
那是「拉伸铺满」为了保住行高做的横向压缩。三段内容（姓名+单位+职务）时
压缩很轻微（约 0.87~1.63 倍，看不出来）；但**单个超长名字**（10 字以上）
会被压到 0.45 倍。这种情况改选「**自动折行铺满**」——字形保持原样，
折成 2 行后字反而更大更端正。

**Q：几段文字大小不一样？**
「拉伸铺满」模式下几段**等高**，只是字数多的那段字被压得更窄一点，
看上去更瘦——这是为了每段都撑满整宽。想让每段字形比例完全一样，
用「自动折行铺满」模式并调整「副标题字号」。

**Q：字形拉伸滑块往大拖，好像没什么变化？**
因为宽度/高度本来就已经撑满了，往大拖只能靠"压低字号"来实现（变扁或变瘦），
幅度确实比往小拖要小。另外**两个轴一起往大拖会互相抵消**（等比放大不会改变字形），
想让字形真的变化，每次只拉一个方向。

**Q：拖了滑块会不会把字拉出框、被裁掉？**
不会。拉伸倍率是乘在"自动铺满"结果之上的，程序会在最后一步重新夹一次
（墨迹宽 ≤ 可用宽、墨迹高 ≤ 行槽高），字号自动让步。
实测把滑块量程两端全组合扫了一遍（43×43 档 × 7 条文本 × 3 种填充方式 = 38829 组），
**溢出为 0**；1.00× 时的排版结果与加滑块之前逐毫米一致。

**Q：想批量打印很多人的台签？**
把所有名字一次性贴进去（一行一个），软件会自动分页，按「打印」全部输出。

## 七、给开发者

源码与构建脚本在同一目录：

| 文件 | 作用 |
|---|---|
| `app.py` | 界面（PySide6 / Qt6），含 `--selftest` 打包自检模式 |
| `core.py` | 排版与绘制核心（纯毫米几何，与设备无关） |
| `verify_compact.py` | 贴边排版 / 切割线 / 文字居中的量化自检（离屏渲染 + 逐像素扫描） |
| `verify_stretch.py` | **拉伸铺满自检**：逐行量墨迹，核对"每段一行、每行撑满整宽、各行等高" |
| `verify_wrap.py` | 折行铺满自检：逐张台签量实际墨迹尺寸、铺满率、是否溢出、居中偏差 |
| `verify_marks.py` | 切割标记自检：定位点是否全在废料内、是否对准刀口、台签区域是否无残留 |
| `verify_slider.py` | **字形拉伸自检**：全量程 43×43 档组合扫一遍，核对不溢出 / 1.00× 无回归 / 形变方向 |
| `smoke_gui.py` | 界面冒烟测试（离屏）：滑块 ↔ 状态 ↔ 配置 ↔ 预览的联动 |
| `simulate_cut.py` | 按 `cut_plan()` 真把渲染图裁开，验证成品尺寸与边缘洁净度 |
| `mkview_fit.py` | 生成"拉伸铺满 vs 自动折行"对比图 |
| `mkview_slider.py` | 生成「字形拉伸」3×3 矩阵示例图 |
| `test_render.py` | 多字体、多字数的渲染自检 |
| `build.bat` | 一键重新打包 exe |

```
# 安装依赖
pip install PySide6-Essentials

# 直接运行
python app.py

# 量化自检：检查台签位置、切割线坐标、文字墨迹居中偏差
python verify_compact.py

# 检查拉伸铺满：每段是否独占一行、每行是否撑满整宽、居中偏差
python verify_stretch.py

# 检查折行铺满：实际墨迹尺寸、铺满率、是否溢出可用方框
python verify_wrap.py

# 检查切割标记：定位点位置、是否落在废料里、成品边缘洁净度
python verify_marks.py
python simulate_cut.py

# 检查字形拉伸：全量程不溢出、1.00× 无回归、形变方向正确
python verify_slider.py

# 界面冒烟（离屏跑，不需要显示器）
python smoke_gui.py

# 重新打包成 exe
build.bat
```

`core.py` 里所有几何量都用**毫米**，绘制时由调用方给出 `mm → 像素` 的比例，
所以预览和打印走的是同一段代码，天生所见即所得。
字号用"墨迹外框（tightBoundingRect）"而不是"行高框"来适配，
这一点决定了文字能否真正顶满台签——行高框比墨迹高约 30%，按行高排版字会明显偏小。

排版入口统一是 `layout_count()` / `layout_positions()`，
它们内部按 `Options.layout` 分派到 `compact_*`（贴边）或 `grid_*`（居中）。
`cut_plan()` 负责算出实际需要下刀的坐标，贴在纸张边缘的那一刀会自动排除。

`tick_segments()` 负责把每条刀口变成"废料区里的 2 个定位点"：
先列出所有台签矩形，再对每个候选位置做**矩形相交测试**（`_rect_is_scrap()`），
只保留完全落在废料里的线段——所以标记永远不会印到成品上，
这是几何上的硬保证，不依赖肉眼估计。

### 拉伸铺满算法（`stretch_plate_text`，默认）

每条 `|` 分段 = 一行，**永不折行**。可用高度按行数等分，每行先按"行槽高"定字号，
再把整行**横向拉伸**到撑满可用宽度：

```
行槽高 = 可用高 / 段数
字号   = 行槽高 × 0.90 / 该行高比
横向   = 可用宽 / (字号 × 该行宽比)     # 这就是那个"把整行塞满"的缩放
```

绘制时用 `painter.scale(sx, 1.0)` 做**非等比缩放**——这正是老工具那种
"字多就压窄、字少就拉宽，总之填满一行"的观感。

缩放有上下限（`STRETCH_MIN=0.45`、`STRETCH_MAX=2.60`）：
压得太狠时反过来**缩小字号保住"撑满整宽"**，拉得太狠时收住让两侧留白，
两种情况都不会让字变形到难看，也不会溢出方框。

### 手动字形拉伸（`Options.stretch_x` / `stretch_y`）

两个方向各自独立，倍率**乘在自动铺满的结果之上**，1.00 表示不动。
算法只有一句：按顺序算字号，**每一步都用更小的约束夹一次**。

    1) em      = 行槽墨迹高 / 该行高比                    # 先按行槽定基准字号
    2) auto_sx = clamp(可用宽 / (em × 该行宽比), 0.45, 2.60)   # 撑满宽度所需的横向倍率
    3) sx      = clamp(auto_sx × 横向滑块, 0.10, 8.00)         # 再乘上手动的横向倍率
    4) em      = min(em, 可用宽 / (宽比 × sx),                 # 横竖都不许溢出
                         行槽墨迹高 / (高比 × 纵向滑块))

第 4 步的两个下限就是"永远不溢出台签"的硬保证。也正因为有它，
横向滑块 > 1 时外观表现为"变扁"而不是"变宽"——宽度方向已经没有余量了；
纵向滑块 > 1 同理表现为"变瘦"。

绘制侧用 `painter.scale(sx, sy)` 做非等比缩放，并且把**墨迹中心**钉在行槽中心
（不再按基线定位），这样任意拉伸下竖直居中都不会漂。

「折行铺满 / 单行等比」两种模式用等效换算实现：先按 `(可用宽 / sx, 可用高 / sy)`
这个"缩小后的方框"求字号，绘制时再放大回来，因此同样不会溢出
（见 `fit_block(..., sx=, sy=)`）。1.00×/1.00× 时两种路径都与加滑块之前**逐毫米一致**。

### 折行铺满算法（`fit_block`，可选）

单行排版时字号被宽度卡死：8 个字在 142mm 宽里只能到 19mm 高，上下白白空着 74%。
所以 `fit_block()` 会**枚举行数 k = 1..6**，每行按 `_split_balanced()`
**等长**劈分（等长才能同时填满宽和高），再算每种 k 的最大字号：

```
em_k = min( 框宽 / 最宽行宽比 ,  框高 / (行高比 + (k-1) × 行距) ) × 0.985
```

然后在"字号接近最优"的候选里（`em ≥ 最优 × 0.96`）挑**覆盖面积最大**的那个，
面积相同则行数少的优先——避免"字只大千分之几却白折一行"。

副标题（`layout_plate_text` 的 `wrap` 分支）是联立求解：主标题要与
`副标题（= 主标题 × 比例）` 加起来正好填满高度，同时各自不超宽。

`_polish_cuts()` 负责避头尾：断点落在 `·` `、` `。` 等**不能作行首**的字符上就往后挪，
落在 `（` `「` 等**不能作行尾**的字符后就往前挪，英文字母/数字中间不断行。
